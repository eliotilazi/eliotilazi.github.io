# Eliot Ilazi | Portfolio

My personal portfolio website, built with **React** and **Vite**, and published with **GitHub Pages**.

Live: https://eliotilazi.github.io

## Run it locally

```bash
npm install
npm run dev
```

## How it is organised

- `src/data.js`: all the content (profile, projects, education)
- `src/App.jsx`: the React components (header, hero, sections, project cards)
- `src/index.css`: the styles, with light and dark mode and a mobile layout
- `.github/workflows/deploy.yml`: builds the site and publishes it automatically on every push to `main`
